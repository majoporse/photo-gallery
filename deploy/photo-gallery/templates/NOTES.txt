1. Rollouts

{{- if .Values.platform.postgres.enabled }}
  kubectl -n {{ .Release.Namespace }} wait --for=condition=Ready cluster.postgresql.cnpg.io/pg --timeout=300s
{{- end }}
{{- if .Values.platform.seaweedfs.enabled }}
  kubectl -n {{ .Release.Namespace }} get seaweed,bucket,s3identity,s3policy,s3policybinding,s3credentials
{{- end }}
  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "photo-gallery.api.fullname" . }} --timeout=180s
  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "photo-gallery.notifier.fullname" . }} --timeout=180s
  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "photo-gallery.web.fullname" . }} --timeout=180s
  kubectl -n {{ .Release.Namespace }} get pods,svc,ingress,certificate

  The API, worker and notifier wait for {{ include "photo-gallery.postgres.host" . }}
  before starting. The migrate Job is a post-install hook and applies the schema.

3. Image host (created by this chart)
{{- if $imageIngress }}

  The ingress only publishes the two bucket prefixes, so SeaweedFS's IAM API is
  not reachable. The 404/403 results are the access-control assertions:

  curl -sI "https://{{ $imageHost }}/?Action=ListUsers" | head -1   # expect 404
  curl -sI "https://{{ $imageHost }}/{{ .Values.config.storagePrivateBucket }}/" | head -1   # expect 403
  curl -sI "https://{{ $imageHost }}/{{ .Values.config.storagePublicBucket }}/" | head -1    # 200/403 until the first upload

  The web pod was given IMAGE_BASE_URL={{ $imageBaseUrl }}. Traefik has no
  default body limit, so a 50 MB direct upload passes through. If your Traefik
  install sets a global limit, exempt this host.
{{- else }}

  No image ingress is rendered. The browser reaches object storage through the
  external endpoint configured for this deployment.
{{- end }}

5. If something is not Ready

  - Missing CRD or operator: apply the cert-manager, CloudNativePG and
    SeaweedFS operators before this chart. The runbook has the commands.
  - Image pulls: the chart creates {{ .Values.secrets.registry.secretName }} from
    secrets.registry.username/.password when both are set.
  - S3 credentials: the app waits for Secret {{ .Values.secrets.storage.secretName }},
    created by the operator unless you supplied both storage keys in values.
  - A configured external database or object store: set
    platform.postgres.connectionString / config.storageEndpoint and disable the
    matching platform section.
